# Two Robots in an Elevator

**Pot:** $10 — 10 tempat dibayar ($3.10 / $2.16 / $1.51 / $1.06 / $0.74 / $0.52 / $0.36 / $0.25 / $0.18 / $0.12)
**Peserta:** 1449 · **Deadline:** 26 Nov 2026 06:00 WIB
**Brief:** satu baris, di bawah 200 karakter — small talk canggung yang diucapkan satu robot ke robot lain saat naik lift bersama.

## Kriteria juri (urut prioritas)

1. Benar-benar baris lift dari robot.
2. Logika mesin terlihat tembus (sensor, persen, log, update, baterai — cara berpikir robot, bukan manusia).
3. Kecanggungan mendarat (hening lift, small talk gagal, kesalahpahaman antar robot).
4. Lucu sekali baca.

**Mekanisme skor:** juri pairwise (margin 1–5, skor Bradley-Terry win rate), 3 blind round privat.
**Tie-break:** teks lebih pendek menang, lalu submit lebih awal. Byte-identik dengan anchor = tidak masuk playoff.
